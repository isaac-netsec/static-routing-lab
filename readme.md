# Static Routing Lab – Cisco Packet Tracer

## Project Overview

This project demonstrates static routing between two separate LANs using Cisco Packet Tracer.

The network consists of two routers connected through a WAN link, with each router serving a separate LAN.

## Network Topology

![Network Topology](network-topology.jpg)

## Network Components

- 2 Routers
- 2 Switches
- End devices (PCs)
- 2 LANs
- 1 WAN connection

## IP Addressing

| Network | IP Address |
|---|---|
| LAN 1 | 192.168.10.0/24 |
| LAN 2 | 192.168.20.0/24 |
| WAN | 10.0.0.0/30 |

## Technologies Used

- Cisco Packet Tracer
- Cisco IOS CLI
- IPv4
- Static Routing

## Verification

Connectivity was tested using:

- show ip route
- show ip interface brief
- ping

The final connectivity test was successful, with 0% packet loss.
